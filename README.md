# TypeScript Compiler

Фронтенд компилятора для подмножества языка TypeScript. Реализованы лексический анализатор (лексер) и синтаксический анализатор (парсер) с построением дерева разбора.

**Стек:** C · Flex · GNU Bison · Graphviz DOT · Visual Studio

## Архитектура

```
Исходный файл .ts
       │
       ▼
┌─────────────┐
│    Лексер   │  lexer.l  — Flex
│ (токенизация)│
└──────┬──────┘
       │ поток токенов
       ▼
┌─────────────┐
│   Парсер    │  parser.y — Bison (IELR)
│   (разбор)  │
└──────┬──────┘
       │ дерево разбора
       ▼
┌──────────────────┐
│  Дерево разбора  │  nodes.h / parsing_tree.c
│   (AST-узлы)     │
└──────┬───────────┘
       │
       ▼
┌──────────────┐
│  DOT-вывод   │  print_functions.c
│  (Graphviz)  │
└──────────────┘
```

Взаимодействие модулей:

- **`lexer.l`** — правила Flex для всех токенов TypeScript, включая многострочные строки, шаблонные литералы и числа в разных системах счисления.
- **`parser.y`** — грамматика IELR на Bison; строит связанные узлы AST через функции из `parsing_tree.c`.
- **`nodes.h`** — декларации всех типов узлов дерева (`ExpressionNode`, `StatementNode`, `FunctionNode`, `VarDeclarationNode` и др.).
- **`parsing_tree.c/.h`** — фабричные функции создания узлов.
- **`print_functions.c/.h`** — обход дерева и генерация DOT-представления.
- **`modifier_head.h`** — вспомогательные структуры для модификаторов переменных (`let` / `const`).
- **`stringBuffer.c/.h`** — буферизация строковых литералов при лексическом анализе.
- **`iohandler.c/.h`** — управление режимом вывода лексера.

## Поддерживаемый синтаксис

### Лексер

**Ключевые слова:** `let`, `const`, `function`, `return`, `if`, `else`, `while`, `do`, `for`, `in`, `break`, `continue`, `switch`, `case`, `default`, `try`, `catch`, `throw`, `finally`, `instanceof`, `new`, `enum`, `as`, `is`, `typeof`

**Типы:** `number`, `string`, `boolean`, `void`, `any`, `unknown`

**Литералы:**
- Целые числа: десятичные, двоичные (`0b...`), восьмеричные (`0o...`), шестнадцатеричные (`0x...`)
- Разделитель `_` в числах: `1_000_000`, `0xFF_FF`
- Числа с плавающей точкой, экспоненциальная запись: `3e+5`, `1.5e-10`
- Строки в одинарных и двойных кавычках с escape-последовательностями
- Шаблонные строки в обратных кавычках с интерполяцией `` `Hello ${name}` ``
- Булевы литералы `true` / `false`

**Операторы:** арифметические, логические, сравнения, составного присваивания (`+=`, `-=`, `*=`, `/=`, `%=`), инкремент/декремент (префиксный и постфиксный), тернарный `? :`, опциональный параметр `?`

**Комментарии:** однострочные `//` и многострочные `/* */`

---

### Парсер

**Объявление переменных:**
```typescript
let x: number = 42;
const name: string = "hello";
let a, b: number, c = 0;          // список объявлений
let arr: string[][] = [["a"]];    // многомерные массивы
```

**Функции:**
```typescript
function add(a: number, b?: number): number {
    return b ? a + b : a;
}
```

**Управляющие конструкции:**
```typescript
if (x > 0) { ... } else { ... }
while (cond) { ... }
do { ... } while (cond);
for (let i = 0; i < n; i++) { ... }
```

**Выражения:**
- Бинарные: `+`, `-`, `*`, `/`, `%`, `&&`, `||`, `==`, `!=`, `<`, `>`, `<=`, `>=`
- Унарные: `!`, унарный `+`/`-`, `++`/`--`
- Тернарный оператор: `a ? b : c`
- Приведение типа: `x as number`
- Доступ к элементу массива: `arr[i][j]`
- Вызов функции: `foo(a, b)`
- Доступ к полю: `obj.field`

Приоритет и ассоциативность операторов явно задан через директивы Bison (`%left`, `%right`, `%nonassoc`).

## Сборка и запуск

### Требования

- Windows
- Visual Studio 2019/2022
- Папка `win_flex_bison-2.5.25` добавлена в переменную окружения `PATH`

### Шаги

**1. Сгенерировать C-файлы из .l и .y:**

```bat
cd CompilatorTS\CompilatorTS
flex_and_bison.bat
```

Скрипт выполняет:
```bat
win_flex lexer.l                              # генерирует lex.yy.c
win_bison --verbose -Wcounterexamples parser.y  # генерирует parser.tab.c / parser.tab.h
```

**2. Скомпилировать** проект в Visual Studio: открыть `CompilatorTS.sln`, собрать конфигурацию `Release` или `Debug`.

**3. Запустить** с тестовым файлом:

```bat
CompilatorTS.exe < test.ts
```

Программа выводит дерево разбора в формате [Graphviz DOT](https://graphviz.org/). Для визуализации:

```bat
CompilatorTS.exe < test.ts | dot -Tpng -o tree.png
```

### Поиск конфликтов в грамматике

```bat
win_bison --verbose -Wcounterexamples parser.y
```

Создаёт `parser.output` с описанием состояний LR-автомата и примерами строк для каждого конфликта.

## Пример работы

**Входной файл `test.ts`:**
```typescript
function hello(num1: number, num2?: number): number {
    if (num2) {
        return num1 + num2;
    } else return num1;
}

let myArray: string[][] = [["apple", "banana"], ["hello"]];
myArray[0][1] = "lime";

for (let i = 0; i < 5; i++) myArray;
while (1) { hello(1); }
do hello(1, 2); while (1);
```

**Результат** — дерево разбора в формате DOT, пригодное для визуализации через [Graphviz Online](https://dreampuf.github.io/GraphvizOnline/) или утилиту `dot`.
